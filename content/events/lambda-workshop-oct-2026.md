Join us for a hands-on workshop on AWS Lambda and serverless computing! In this session, you'll build your first serverless API from scratch — no servers to manage, no infrastructure headaches.

## What you'll learn

- What serverless means and when to use it
- Creating and deploying Lambda functions
- Connecting Lambda to API Gateway
- Storing data with DynamoDB
- Best practices for cold start optimization

## Prerequisites

- AWS Free Tier account (see our [setup guide](/guides/aws-account-setup))
- Basic Python or JavaScript knowledge
- Laptop with a browser

## What to bring

Your laptop, curiosity, and enthusiasm! All hands-on labs run in the browser via AWS CloudShell.
